# Wörtli-Frosch

Französisch-Wörter der 6. Klasse (Schweiz) lernen mit Léo, dem Frosch: Lernkarten, Hören, Wählen, Schreiben (Puzzle und Tastatur
mit Akzenten), Memory und Wörtlitest – für das «Vocabulaire» und das «Vocabulaire plus» der Unités 1 und 2. Mit jedem
Lernfortschritt gibt es einen neuen Sticker fürs Stickeralbum – in Unité 2 Päckchen für das Panini-Album der Frosch-WM
(seltene Glitzer- und Gold-Sticker, Doppelte tauschen). Fürs iPad, iPhone und den PC; läuft auch ohne Internet
(Safari → Teilen → «Zum Home-Bildschirm»).

Dieser Ordner wird von `Scripts/bauen.py` im Projekt `Woertlifrosch` erzeugt – hier nichts von Hand ändern, es wird überschrieben.
