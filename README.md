# Wörtli-Frosch

Französisch-Wörter der 6. Klasse (Schweiz) lernen mit Léo, dem Frosch: Lernkarten, Hören, Wählen, Schreiben (Puzzle und Tastatur
mit Akzenten), Memory und Wörtlitest – für das «Vocabulaire» und das «Vocabulaire plus». Mit jedem Lernfortschritt gibt es einen
neuen Sticker fürs Stickeralbum. Fürs iPad, iPhone und den PC; läuft auch ohne Internet (Safari → Teilen → «Zum Home-Bildschirm»).

Dieser Ordner wird von `Scripts/bauen.py` im Projekt `Woertlifrosch` erzeugt – hier nichts von Hand ändern, es wird überschrieben.
Bilder: OpenAI. Stimme: ElevenLabs. Schriften «Nunito» und «Andika» unter der SIL Open Font License (`fonts/OFL-*.txt`).
